    File format
    • First row = column headers. One device per row.
    • Rows whose Asset ID already exists update that device; others are created.
    • Owner = username, email or full name of an existing user.
    • Last calibration date (DD.MM.YYYY) creates a history entry; the next date is calculated from the interval.
    • Manufacturer and Model are matched to the brand list ignoring upper/lower case; missing ones are added automatically.
    • Columns named exactly like a custom field of the row’s manufacturer or model (e.g. “Range”) fill that field. Only manufacturers and models that already exist have fields.
